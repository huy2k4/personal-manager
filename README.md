# Personal Manager

Ứng dụng Quản lý Cá nhân (Personal Manager) được xây dựng với [Next.js](https://nextjs.org) (App Router) và TypeScript.

## Cài đặt và Khởi chạy

Chạy dev server:

```bash
npm run dev
```

Mở trình duyệt tại [http://localhost:3000](http://localhost:3000) để xem trang **Hello World**.

## Các lệnh có sẵn

- `npm run dev`: Chạy development server với Turbopack
- `npm run build`: Build ứng dụng cho production
- `npm run start`: Chạy server production sau khi build
- `npm run lint`: Kiểm tra lỗi cú pháp với ESLint
